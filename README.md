## About

I build systems where software meets the physical world — **AI**, **robotics**, **IoT**, and the embedded firmware underneath.

- Landslide early-warning through satellite and ground sensor fusion
- Quadruped robots that take natural-language commands, running AI locally
- Fixed-wing UAVs with flight controllers written from scratch
- Learning platforms that keep local heritage alive

### Yuki

**AI-Powered Quadruped Robot**

<img src="https://img.shields.io/badge/Ollama-000000?style=flat-square&logo=ollama&logoColor=white" alt="Ollama" />
<img src="https://img.shields.io/badge/Phi--3-00D9FF?style=flat-square&logo=microsoft&logoColor=0F2027" alt="Phi-3" />
<img src="https://img.shields.io/badge/ESP32-E7352C?style=flat-square&logo=espressif&logoColor=white" alt="ESP32" />
<img src="https://img.shields.io/badge/C++-00599C?style=flat-square&logo=cplusplus&logoColor=white" alt="C++" />

A quadruped that runs its language model on-device. Speak to it, and it plans and executes the motion.

- Local AI inference with Ollama + Phi-3 — no cloud round-trip
- Natural language command execution
- WiFi-based communication and modular robotic architecture
